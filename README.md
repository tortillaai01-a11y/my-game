# Хомяк: кормовой переворот

Браузерный 3D-шутер на Three.js. Игрок — хомяк с пакетиком корма. Шесть ботов преследуют игрока и стреляют; у всех 100 HP. Арена — большая клетка с наполнителем, укрытиями и статуей хомяка.

## Запуск

Требуется Node.js 22.12+ (проверено на 24).

```sh
npm ci
npm run dev
```

Открой адрес, который выведет Vite, в настольном браузере с WebGL. Нажми «Войти в клетку», чтобы захватить мышь.

WASD — движение, мышь — прицел, ЛКМ — стрельба, Shift — бег, R — перезарядка, Escape — пауза. Пакет вмещает 24 выстрела, запас бесконечный. Попадание кормом наносит 25 урона, выстрел бота — 10. Победа — уничтожить всех ботов. После победы или поражения можно начать заново.

```sh
npm test
npm run build
npm run preview
```

Модели созданы процедурно, внешние игровые ресурсы и ключи API не нужны. Интернет для игры не требуется; при недоступности Google Fonts используются системные шрифты.

Браузерная проверка: `npm run test:e2e`. Используется Chromium из `/usr/bin/chromium`; другой путь можно передать через `CHROMIUM_PATH`.
